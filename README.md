# InvoiceReceiptMail

EC-CUBE 4.2 / 4.3 用のプラグインです。請求書・領収書の PDF をつくって、お客様にメールで送ります。

- 注文メールに **請求書 PDF を自動で添付**
- 受注が「入金済み」になったら **領収書 PDF を自動で送信**
- 会員は **マイページから領収書をダウンロード**（宛名・但し書きの変更、再発行の表示つき）
- **インボイス制度（適格請求書）の記載事項に対応**：登録番号、税率ごとの対象額と消費税額、軽減税率の ※ 表示

紹介記事：[EC-CUBE 4.2 / 4.3 で請求書・領収書をメールで送るプラグインを公開しました](https://mdsgn.me/posts/eccube-invoice-receipt-mail)

## 対応バージョン

| EC-CUBE | 状態 |
|---|---|
| 4.3 | 本番環境で稼働中 |
| 4.2 | 4.2.3 + PHP 8.1 で動作確認済み |

4.0 / 4.1 には対応していません（登録番号は 4.2 で追加された店舗設定の項目を使うため）。

## できること

### 請求書

- 設定で選んだ支払方法（銀行振込など）の注文では、注文完了メールに請求書 PDF を添付します。
- 「注文時に支払いが完了する支払方法」（クレジットカードなど）に指定した支払方法では、請求書に「お支払済み」とお支払日を表示し、備考（振込先など）は表示しません。
- 管理画面の受注編集から、PDF の表示とメールでの再送ができます。

### 領収書

- 受注の対応状況が「入金済み」に変わったときに、1 回だけ自動で送ります。管理画面での変更・一括変更、決済プラグインによる変更のどれでも動きます。
- 「入金済み」を飛ばして「発送済み」にした場合も、まだ送っていなければ送ります。
- 2 回目以降の発行は「再発行」と表示します。
- 管理画面の受注編集から、PDF の表示とメールでの送信ができます。

### マイページ

- 会員のお客様が、注文履歴の詳細画面から領収書 PDF をダウンロードできます。
- 宛名・但し書きをお客様が変えられるようにするかを選べます。
- 対象は「入金済みになったら領収書を送信」で選んだ支払方法の、入金済み・発送済みの注文です。

### 送信の記録

受注編集画面に、請求書・領収書の送信と発行の履歴（日時・帳票番号・自動／手動／マイページ・送信先または宛名）を表示します。

### 帳票の内容

- 帳票番号は、請求書が `INV-注文番号`、領収書が `RCP-注文番号` です。
- 発行者の会社名・住所・電話番号・登録番号は、EC-CUBE の「設定 > 店舗設定 > 基本設定」の値を使います。
- 社印の画像（PNG / JPEG、2MB まで）を発行者欄に重ねて表示できます。背景が透明な PNG がおすすめです。
- 宛名は、注文に会社名があれば「会社名 御中」、なければ「お名前 様」です。

## インストール

1. このリポジトリから、プラグインのファイルが最上位に並んだ tar.gz をつくります。

   ```bash
   git archive --format=tar.gz -o InvoiceReceiptMail.tar.gz HEAD
   ```

   [Releases](../../releases) に tar.gz を置いている場合は、それを使えます。

2. EC-CUBE の管理画面「オーナーズストア > プラグイン > プラグイン一覧」で「アップロードして新規追加」から tar.gz をアップロードします。
3. 一覧で「有効化」します。
4. 「設定」から、送信する支払方法・帳票の内容・メールの件名などを確認します。

有効化したとき、表示中の支払方法のうち名前に「銀行振込」「クレジット」を含むものを請求書・領収書の対象に、「クレジット」を含むものを「注文時に支払いが完了する支払方法」に初期設定します。必ず設定画面で確認してください。

## 設定項目

| 項目 | 内容 |
|---|---|
| 請求書を注文メールに添付 | 請求書を添付する支払方法 |
| 入金済みになったら領収書を送信 | 領収書を自動で送る支払方法 |
| 注文時に支払いが完了する支払方法 | 請求書に「お支払済み」と表示する支払方法 |
| 請求書の備考 | 振込先・お支払期限など |
| 領収書の但し書き | 初期値「お品代として」 |
| 社印 | 発行者欄に重ねる画像 |
| マイページの領収書 | ダウンロードを許可するか、宛名・但し書きの変更を許可するか |
| メールの件名・本文 | 領収書メールの件名と本文の冒頭、請求書を再送するメールの件名 |

送信元・BCC・返信先は、店舗設定のメールアドレスを使います。

## データの保存先

- 設定と送信の記録はプラグイン用のテーブルに保存します。
- 社印の画像は `app/PluginData/InvoiceReceiptMail/` に保存します。

## 注意

- 帳票の内容が適格請求書として要件を満たしているかは、店舗ごとの事情（取引の内容、登録番号の設定など）によります。運用前に、実際の注文で出した PDF を確認してください。
- 現状のまま提供します。不具合の報告は Issue で受け付けますが、対応はできる範囲で行います。
- 使い方や組み込みのご相談は [MDesign](https://mdsgn.me/contact) まで。
